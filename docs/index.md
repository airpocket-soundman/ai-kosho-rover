# AI小姓ローバー

人の行動を観察し、次に必要になりそうな小物を載せた「台」を少しだけ先回りして届ける、家庭の玄関・廊下向けの小型メカナムローバーを作るプロジェクトです。
羽柴秀吉が信長の草履を懐で温めていた逸話にならい、命令されてから動くのではなく「察して先回りする」ロボットを目指します。

現在は**企画・詳細検討の段階**です。動作する実機はまだありません。

## 決めた方針(2026-09-24 時点)

| 項目 | 方針 |
| --- | --- |
| 駆動 | Geekservo の DC モーター(LEGO 互換)×4 でメカナム 4 輪を駆動 |
| フレーム | LEGO Technic で製作。低い車高で「台」の下に潜り込む |
| 搬送 | ロボットアームは使わず、台の下に潜ってリフトで持ち上げて運ぶ(倉庫ロボット方式) |
| 頭脳 | Arduino UNO Q(Linux 側で画像認識・判断、MCU 側でモーター・安全停止) |
| カメラ | ESP32-CAM 等を Wi-Fi でストリーミングし、UNO Q 側で解析 |
| 自己位置 | 外部固定カメラ + ローバー上面の AprilTag で推定(車輪エンコーダーは使わない) |
| 玄関の人検出 | 外部固定カメラで来訪・帰宅・扉の開閉を検出 |
| 認識モデル | ローバー視点(下半身)の画像を収集し、自分でラベリングして検出モデルを学習 |
| 判断 | LAYA(オープンな型付き Decision Model)で高レベル行動を選択。走行制御は古典制御 |
| 公開 | 計画と進捗をこのサイト(GitHub Pages)で公開 |

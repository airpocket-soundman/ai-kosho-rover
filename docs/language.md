ローバーが話す電子音の言語体系「小姓語(こしょうご)」の仕様です。家族には「音の雰囲気」で伝わればよく、裏側では機械的に符号化・復号できるように設計しています。ブラウザで動く[デコーダー / 合成器](../decoder/)で、文を音にしたり、マイクで聞いた音を日本語に訳したりできます。

## 1. 裏設定

小姓語は、言葉を持たない小姓が主の邪魔をせずに気持ちを伝えるために作った口笛の体系、という設定です。

- 主に話しかけてはいけない。だから短く、小さく、必要なときだけ鳴らす。
- 言い切ると押しつけがましいので、文の終わりは小さな「息」(短いノイズ)で締める。
- 帰る人には下がる音、出て行く人には上がる音。方向が気持ちを表す。
- 困ったときは音が揺れる。嬉しいときは少し速くなる。

R2-D2 の鳴き声と同じく、意味は「音の形」に乗せ、感情は「速さ」に乗せます。

## 2. 音節(音素)

1 つの音節は「高さ」と「形」の組み合わせです。長さは 120 ms を基本にします。

### 2.1 高さ(3 段)

| 記号 | 名前 | 中心周波数 | 範囲(復号時) |
| --- | --- | --- | --- |
| 1 | 低 | 650 Hz | 460〜920 Hz |
| 2 | 中 | 1,300 Hz | 920〜1,840 Hz |
| 3 | 高 | 2,600 Hz | 1,840〜3,700 Hz |

段の間は 1 オクターブ離し、復号時は対数周波数で最も近い段に割り当てます。

### 2.2 形(5 種 + 句読点)

| 記号 | 名前 | 音の動き | 合成の定義 |
| --- | --- | --- | --- |
| L | 平 | ─ 一定 | 中心周波数で一定 |
| R | 上昇 | ↗ | 中心 ÷ 1.22 から中心 × 1.22 へ指数的に上がる(全体で 1.5 倍) |
| F | 下降 | ↘ | R の逆 |
| P | 山 | ∧ | 中心から × 1.3 まで上がり、中心へ戻る |
| W | 揺れ | 〜 | 中心を 20 Hz、±8 % で震わせる |
| K | 息 | (短いノイズ) | 30 ms の白色ノイズ。文の終わり |

音節の書き方は「形 + 高さ」で、`R2` なら「中の高さで上昇」です。

### 2.3 時間

| 項目 | 値 |
| --- | --- |
| 音節の長さ | 120 ms(立ち上がり 8 ms、減衰 15 ms) |
| 語の中の音節の間 | 40 ms |
| 語と語の間 | 160 ms |
| 文の終わり | 160 ms の間を置いて K、または最後の音節を 300 ms に伸ばす(疑問) |
| 文と文の間 | 500 ms 以上 |
| 音色 | 正弦波に第 2 倍音を 1/4 で重ねる |

1 文は最大 4 語・8 音節で、およそ 2 秒以内に収めます。

## 3. 語彙

語は 1〜3 音節です。同じ種類の語は似た形にし、家族が耳で覚えやすくしています。

### 3.1 対象(誰・何)

| 日本語 | 転写 | 覚え方 |
| --- | --- | --- |
| お父さん | `L2 F1` | 中で平、低く落ちる |
| お母さん | `L2 R2` | 中で平、中で上がる |
| 子ども | `L2 P3` | 中で平、高く山 |
| みんな | `L2 W2` | 中で平、中で揺れる |
| わたし(ローバー) | `L1` | 低く 1 音 |
| 台 | `F2 L2` | 落ちて平 |
| 扉 | `P2 P2` | 山が 2 つ |
| 傘 | `W1 R2` | 雨の揺れから上がる |

対象を表す語は「`L2` で始まる = 人」「それ以外 = 物」という規則です。

### 3.2 述語(何をする・どうした)

| 日本語 | 転写 | 覚え方 |
| --- | --- | --- |
| 持ってきたよ | `R2 R3 W3` | 上がって上がって、嬉しく揺れる |
| おかえり | `F3 F2` | 高いところから 2 回下がる |
| いってらっしゃい | `R2 R3 L3` | 上がって上がって、伸びる |
| 見に行くね | `P1 R3` | 低い山から高く上がる(語尾上がり) |
| 迷っている | `W2` | 中で揺れる |
| あっ(止まった) | `F1` | 低く短く落ちる |
| 帰るね | `F2 F1` | 中から低へ 2 回下がる |
| ただいま(着いた) | `P1` | 低い小さな山 |
| 充電中 | `W1` | 低く揺れる |
| 待ってるね | `L2` | 中で平 |
| 受け取ったよ、ありがとう | `R1 P2` | 低く上がって中で山 |
| 了解 | `R2` | 中で上がる |
| できない、いいえ | `F1 F1` | 低く 2 回落ちる |
| どいて、危ない | `P3 P3 P3` | 高い山を 3 回(唯一の強い音) |

帰宅に関する語は下降(F)、外出に関する語は上昇(R)で作っています。

### 3.3 補語(状況)

| 日本語 | 転写 | 覚え方 |
| --- | --- | --- |
| 雨 | `W1 W1` | 低い揺れが 2 つ(雨粒) |
| 急いで | `R3 R3` | 高く 2 回上がる |
| 電池が少ない | `F1 W1` | 落ちて弱く揺れる |

### 3.4 雑談(人がそばにいるときの、ひとこと)

雑談は 1 語で文になります。対象を付けず、言い切りは K、問いかけは最後を伸ばします。

| 日本語 | 転写 | 覚え方 |
| --- | --- | --- |
| おはよう | `L1 R2 P3` | 低いところから起き上がる |
| おやすみ | `F3 F2 F1` | 3 回下がって沈む |
| いってきます | `R1 R2 R3` | 3 回上がって出て行く |
| またね | `F2 L3` | 下がってから高く残る |
| いい天気だね | `L2 R2 L3` | 中から上がって明るく伸びる |
| 寒いね | `L2 F1 L1` | 低く縮こまる |
| 暑いね | `L2 P3 L2` | 高い山をひとつ |
| 眠い | `F2 F2 W1` | 下がって、低く揺れる |
| 充電したいな | `W1 R1` | 充電中の揺れから、少し上がる |
| 靴、そろってるよ | `F1 L1 L1` | 落ちて、低く並ぶ |
| 誰か来た? | `P2 R3~` | 中の山から高く上がる(伸ばす) |
| 今日はどうだった? | `L2 P2 R3~` | 平、山、上がる(伸ばす) |
| ちょっと待って | `L2 L2` | 待ってるねを 2 回 |
| ごめんね | `F2 W2` | 下がって、揺れる |
| うれしい | `P3 W3` | 高い山から嬉しく揺れる |
| 静かだね | `L1 L1` | 低い平が 2 つ |
| 退屈 | `L1 L1 L1` | 低い平が 3 つ |
| え? | `R3~` | 高く上がる 1 音(伸ばす) |
| ふむ | `P1 L1` | 低い山から平 |
| へえ | `L3 F2` | 高い平から下がる |

「低い平が並ぶほど静か・退屈」「起きる・出て行くは上昇の連続」「沈む・眠るは下降の連続」という規則です。

### 3.5 独り言(誰にも向けていない言葉)

独り言は文の終わりに息(K)を付けません。誰にも向けていないので言い切らず、小さく(−6 dB)、遅く(テンポ 1.3)消えていきます。復号では 400 ms の無音で文が閉じます。

| 日本語 | 転写 | 覚え方 |
| --- | --- | --- |
| 床がつめたい | `F1 L1 W1` | 落ちて、低く震える |
| 廊下が長い | `L1 L1 R1` | 低く続いて、少し上がる |
| 月が見えない | `F3 F1` | 高いところから一気に落ちる |
| 埃と友達 | `W1 W2` | 低い揺れが少し上がる |
| 主(あるじ)はいまどこ | `L2 F2 W2` | 平、下がって、揺れる |
| 草履を温めている | `R1 W1 R1` | 低く上がり、揺れ、また上がる(裏設定の核心) |
| 影が動いた | `F3 W3` | 高く落ちて、高く揺れる |
| 誰もいない | `L1 F2 F1` | 低い平から 2 回下がる |
| 夢を見た | `W1 P3 W1` | 揺れの間に高い山(充電中に見る夢) |
| 思案中 | `P1 P1 P1` | 低い山を 3 つ |
| 雨の匂い | `W1 W1 F1` | 雨粒のあとに落ちる |
| 昔のことを思い出す | `F1 P1 F1` | 落ちて、山、落ちる |
| 壁と話した | `L1 W1 L1` | 平、揺れ、平 |
| 数えている | `R1 R1 W1` | 数のあとに揺れる |

### 3.6 数

低い上昇 `R1` を数だけ繰り返します。靴の数や来た人の数を独り言で数えるときに使います。

| 数 | 転写 |
| --- | --- |
| 1 | `R1` |
| 2 | `R1 R1` |
| 3 | `R1 R1 R1` |

例: 「靴、そろってるよ、3」 = `F1 L1 L1 / R1 R1 R1 / K`

## 4. 文法

```text
文     = [注意] [対象] 述語 [補語 ...] [数] 終止
雑談文 = 雑談語 終止
独り言 = 独り言語 [数]              (終止なし。400 ms の無音で終わる)
注意   = L3 を 1 音(遠くの人に向けるときだけ)
終止   = K(言い切り) | 最後の音節を 300 ms に伸ばす(問いかけ)
```

- 語順は「対象 → 述語 → 補語」。対象は省略できる(省略時は目の前の人)。
- 語の切れ目は 160 ms の間。復号時は 100 ms 以上の無音を語の境界とみなす。
- 1 文は最大 4 語。長くなるなら 2 文に分ける。

### 4.1 例文

| 場面 | 日本語 | 転写 |
| --- | --- | --- |
| 台を差し出す | お父さん、持ってきたよ | `L2 F1 / R2 R3 W3 / K` |
| 帰宅した人を迎える | お母さん、おかえり | `L2 R2 / F3 F2 / K` |
| 雨の日の見送り | いってらっしゃい、雨だよ、傘 | `R2 R3 L3 / W1 W1 / W1 R2 / K` |
| 観察に行く | 見に行くね? | `P1 R3~`(最後を伸ばす) |
| 電池が少ない | 電池が少ないから帰るね | `F1 W1 / F2 F1 / K` |
| 接触した | あっ | `F1 / K` |
| 充電ステーションに着いた | ただいま | `P1 / K` |
| 荷物を受け取った | ありがとう | `R1 P2 / K` |

`/` は語の区切り、`~` は伸ばす印です。

### 4.2 いつ話すか

| 種類 | きっかけ | 頻度・条件 |
| --- | --- | --- |
| 述語の文 | 行動状態機械の遷移(台を差し出した、扉が閉まった、など) | 遷移ごとに 1 回 |
| 雑談 | 人がローバーの 1 m 以内に 10 秒以上留まり、実行中のタスクがないとき | 1 回だけ。時刻で「おはよう / おやすみ」、天気で「いい天気 / 寒い / 暑い」を選ぶ |
| 独り言 | 充電ステーションで待機中、近くに誰もいないとき | 昼間だけ、20〜40 分に 1 回、−6 dB。雨なら「雨の匂い」、夜なら「月が見えない」、長く誰も来なければ「誰もいない」「退屈」、靴を見たら「数えている」+ 数 |
| 相づち | 人が話しかけたとき(音声の有無だけを検出) | 「ふむ」「へえ」「え?」を 1 回 |

家族が近くにいるときは独り言を言いません。独り言なので、聞かれないのが本来です。

## 5. 感情と場面(韻律)

意味は音の形で決まり、感情は速さと大きさで乗せます。復号には影響しません。

| 状態 | テンポ | 音量 |
| --- | --- | --- |
| 嬉しい | 0.85 倍(速い) | 通常 |
| 通常 | 1.0 倍 | 通常 |
| 困っている | 1.3 倍(遅い) | 通常 |
| 独り言 | 1.3 倍(遅い) | −6 dB |
| 夜(22 時以降) | 通常 | −12 dB |
| 深夜(0〜6 時) | 通常 | 「どいて」「あっ」以外は鳴らさない |

## 6. 復号の手順(デコーダー)

1. 音声を 1,024 サンプル(約 23 ms)の窓、約 3 ms 刻みで解析する。
2. 各窓で、400〜4,000 Hz の範囲のスペクトルの最大点を放物線補間して周波数を出す。スペクトルが平坦(幾何平均 ÷ 算術平均が高い)なら「息(K)」の候補にする。
3. 音のある窓が連続した区間を 1 音節とする。音節内のピークの 12 % 未満を無音とみなし、8 ms 以上の無音で区切る。長さ 60〜450 ms 以外は捨てる。
4. 音節ごとに、対数周波数の中央値で高さ(1〜3)を決め、前・中・後の平均と揺れの大きさで形(L / R / F / P / W)を決める。揺れは、直線を引いた残差の符号反転が毎秒 25 回以上あるとき(20 Hz の揺れで約 40 回、山は約 17 回)。
5. 音節の間が 100 ms 未満なら同じ語、以上なら別の語にする。K または 400 ms 以上の無音で文を閉じる。最後の音節が 240 ms 以上なら問いかけ。
6. 語を辞書で引き、日本語に並べる。辞書にない語はそのまま転写で示す。

## 7. 実装上の取り決め

- 辞書と文法の正本は[デコーダー / 合成器](../decoder/)の JavaScript にある辞書オブジェクトとし、このページはそれを写したもの。語を足すときは両方を更新する。
- ローバー側は、行動状態機械の遷移に文(転写)を割り当て、合成した WAV を microSD に入れて DFPlayer Mini で再生する。WAV はデコーダーアプリの書き出し機能で作る。
- 語彙は家族が覚えられる範囲(述語 8 種程度)を日常で使い、残りはデコーダーで読める「裏の語彙」として持つ。
- 語を足すときは、転写(音節の並び)が既存の語と重ならないことと、3 テンポで解読できることを、デコーダーの自己診断(`selfTest()`)で確かめる。

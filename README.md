# AI小姓ローバー

人の行動を観察し、次に必要になりそうな小物を少しだけ先回りして届ける、家庭の玄関・廊下向けメカナムローバーの開発プロジェクトです。

現在は**企画・詳細検討の段階**です。動作するローバーや実装済みのAIモデルはまだありません。構想の全文は[企画書](docs/AI_Kosho_Rover_Project.md)に保存しています。

開発計画と進捗は GitHub Pages で公開しています: <https://airpocket-soundman.github.io/ai-kosho-rover/>

## 目指す体験

- 外出の兆候を捉え、その人の財布・鍵などを載せたトレーを玄関へ届ける。
- 帰宅時には空のトレーを差し出し、受け取った物を収納場所へ戻す。
- 判断に必要な情報が足りなければ、見える位置へ移動して確かめる。
- 人が話しかけたりアプリを操作したりしなくても、必要な場面で支援する。

## 想定する構成

```text
カメラ・ToF・IMU・エンコーダ・ドア・トレー状態
                  ↓
       観測と自己位置推定
                  ↓
    行動予測・Decision Model
                  ↓
       タスク選択 / vx, vy, omega, lift
                  ↓
       衝突防止のSafety Layer
                  ↓
      メカナム4輪・トレー用リフト
                  ↓
             結果を再観測
```

Decision ModelにはJEV系やLAYAを候補として検討します。Arduino UNO系ボード上での実行可能性、推論速度、入出力形式、連続的な速度指令への対応は**未検証**です。実機の制約を測定してから採用構成を決めます。衝突防止と非常停止はモデルの判断から独立させます。

## 最初の開発段階

1. **実行環境の確認**: ボードのCPU・NPU・RAM、モデル要件、センサーとモーターの接続条件を調べる。
2. **走行と安全の試作**: 4輪の速度制御、近接停止、バンパー停止、手動停止を動作確認する。
3. **トレーの搬送**: 定位置への接近、リフト、重量検出、収納位置への復帰を検証する。
4. **観測と判断**: 人の動き・ドア・トレー状態を時系列で扱い、外出と帰宅を識別する。
5. **閉ループ評価**: 不確実な場面での観測位置変更、介入の適切さ、安全性を家庭に近い環境で測る。

実装の追加時には、使用したボード、配線、再現手順、評価結果をこのリポジトリに記録します。

## データと安全

家庭内の映像、人物識別用データ、行動ログ、認証情報はリポジトリに保存しません。実験データは本人の管理下で扱い、公開可能な例だけを匿名化して追加します。人や障害物の近くで実機を動かす前に、独立した停止手段を検証します。
